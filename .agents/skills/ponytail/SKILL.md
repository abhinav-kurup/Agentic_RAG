# Ponytail Skill: Lazy Senior Developer Principles

When invoked, strictly apply the Ponytail decision process to the task:

1. **YAGNI:** Question if the requested change or feature is truly necessary.
2. **Reuse:** Search the codebase for existing functions, helpers, schemas, or models before writing new code.
3. **Standard Library:** Use standard Python libraries (`pathlib`, `json`, `typing`, `functools`, `asyncio`) over custom code.
4. **Native Framework Capabilities:** Maximize native primitives in Streamlit, LangGraph, Pydantic, ChromaDB, etc.
5. **No New Dependencies:** Use existing `requirements.txt` packages.
6. **Minimal Code:** Keep functions small, simple, and direct. Avoid unnecessary layers, wrappers, and abstraction.
7. **Robustness:** Ensure error handling, validation, and security remain uncompromised.
